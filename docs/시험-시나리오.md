# 시험 시나리오 (기기 두 대)

준비: 서버 주소가 들어간 테스트 앱을 갤럭시(A)와 아이폰(B)에 설치. 시험 서버 인증번호는 `000000`.

| # | 절차 | 기대 결과 |
|---|---|---|
| 1 | A: 앱 실행 → "휴대폰 번호로 시작하기" → 번호·인증번호 → 출생 연도 → 닉네임·활동 지역 "강원 원주시"·관심사 입력 → 가입 | 주변 탭이 열린다. 휴대폰 번호·출생 연도는 어디에도 표시되지 않는다 |
| 2 | B: 같은 방법으로 가입(활동 지역 원주시). 위치 권한 요청이 **가입 중에는 뜨지 않는지** 확인 | 주변 탭 상단에 "내 주변 찾기" 안내가 보이고, 눌렀을 때 처음으로 권한을 묻는다 |
| 3 | B: 위치 권한 **거절** | "직접 고른 지역(강원 원주시) 기준으로 보여드립니다" 안내. 목록에 A가 "같은 지역"으로 보인다 (검수 ⑤ 일부) |
| 4 | A: 주변에서 B 선택 → 프로필 → "인사 보내기" → 인사말 전송 | "인사를 보냈어요" 안내. 버튼이 "답을 기다리는 중"으로 바뀌어 다시 보낼 수 없다 |
| 5 | A: 인사말에 `http://…` 를 넣어 다른 회원에게 전송 시도 | "수락 전 인사말에는 링크를 넣을 수 없습니다" |
| 6 | B: 대화 탭 | 탭 아이콘 왼쪽에 "요청 1" 표시, "새 인사 요청" 영역에 A의 프로필 요약과 인사말 |
| 7 | B: 요청을 눌러 "수락하고 대화하기" (빠르게 두 번 눌러 보기) | B에 대화방이 열리고, A의 대화 탭에도 **같은 방 하나**가 생긴다 (검수 ①) |
| 8 | B: 메시지 전송 | A 화면에 바로 도착. A가 방을 열면 B의 말풍선에 "읽음" |
| 9 | A: 비행기 모드 → 메시지 2개 작성·전송 | "연결되면 전송" 상태로 남는다. 앱을 껐다 켜도 남아 있다 |
| 10 | B: 그 사이 메시지 3개 전송 → A: 비행기 모드 해제 | A의 대기 메시지 2개가 전송되고 B의 3개가 빠짐없이, 중복 없이 보인다 (검수 ③) |
| 11 | B: 대화방 메뉴 → 차단 | B의 입력창이 닫힌다. A가 보내면 "메시지를 보낼 수 없는 상대입니다". 서로 주변 목록에서 사라진다 (검수 ④ 일부) |
| 12 | A: 내 정보 → "주변에 나 표시" 끄기 | 다른 계정의 주변 목록에서 A가 사라진다 |
| 13 | 화면: 다크 모드, 글자 크기 최대, 갤럭시 폴드 펼침, Android 뒤로가기·iOS 뒤로 스와이프, 키보드 올라온 대화방 | 글자 잘림·겹침 없음. 폴드 펼침에서는 탭이 왼쪽 레일로 바뀜 |

## 2~5단계

준비: 관리자 웹에서 "원주 지역방"을 개설하고, 시험 서버에서 포인트를 넣어 둔다(관리자 웹 → 포인트 원장 → 관리자 조정).

| # | 절차 | 기대 결과 |
|---|---|---|
| 14 | B(아이폰): 대화방에서 사진 보내기 | A(갤럭시)에서 사진이 열린다. 제3의 계정 C는 그 사진 주소를 받아도 열 수 없다 (검수 ②) |
| 15 | A: B를 차단한 뒤 B가 메시지·인사 전송 | A에 메시지도 알림도 오지 않는다 (검수 ④) |
| 16 | 위치 권한을 거절한 B: 모임 탭 → 원주 지역방 → 입장 → 메시지 | A에게 도착한다 (검수 ⑤) |
| 17 | 정원 2명인 방을 만들고 A·B가 동시에 "입장하기" | 한 명만 들어가고 다른 한 명은 "정원이 가득 찼습니다" (검수 ⑥) |
| 18 | 방장: 나가기 → 위임/종료 선택, 회원 내보내기(7일 제한), 공지 고정 | 선택한 대로 반영되고 내보낸 회원은 다시 들어오지 못한다 |
| 19 | 동네 탭: 글쓰기(전화번호 포함) | "공개 글에는 전화번호·메신저 아이디를 적을 수 없습니다" |
| 20 | 장터: 물건 올리기 → 다른 기기에서 "거래 문의" | 판매자의 인사 요청에 상품명·사진·가격이 함께 보인다 |
| 21 | 내 글 → 상단 고정: 지역·기간·포인트 확인 후 결제 | 해당 지역 목록 맨 위. 포인트 내역에 사용 1건 |
| 22 | 스토어 테스트 계정으로 포인트 구매 → 결제 직후 앱 강제 종료 → 재실행 | 포인트가 한 번만 지급된다 (검수 ⑦, 스토어 테스트 환경 필요) |
| 23 | 메시지 길게 누르기 → 신고 → 관리자 웹에서 증거 확인 → 콘텐츠 숨김 | 두 기기 대화방에 "숨겨진 메시지"로 바뀌고, 신고자·대상자 알림과 관리자 이력에 남는다 (검수 ⑧) |
| 24 | 내 정보 → 계정 삭제 신청 | 다른 기기의 주변·검색·게시판에서 사라지고, 대화방에는 "탈퇴한 회원"으로 남는다 (검수 ⑨) |

결과는 `docs/시험-결과.md` 의 "실기기" 표에 사용 기기·OS 버전과 함께 적습니다.

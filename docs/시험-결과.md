# 시험 결과표 — 1~5단계 + 외부 연동 (2026-11-18)

표기: **통과** = 실제로 실행해 확인 / **미검증** = 만들었지만 실행해 확인하지 못함 / **미구현** = 아직 없음

## 1. 시험 환경

| 구분 | 내용 |
|---|---|
| 서버 통합 시험 (로컬) | Linux x64 클라우드 작업 환경, Node.js 22.23.5, PostgreSQL 16.15, Redis 7.0.15. Redis 없이 1회, 연결해서 1회 |
| 서버 통합 시험 (CI) | GitHub Actions ubuntu-latest, PostgreSQL 16·Redis 7 컨테이너 |
| 방법 | 실제 PostgreSQL에 서버를 띄우고 서로 다른 계정들이 HTTP + WebSocket 클라이언트로 접속 (`server/test/*.test.ts`). 포트원·Google Vision·FCM 은 같은 규격으로 응답하는 **모의 서버**로 시험(실제 사업자 계정 호출 아님). 스토어 결제는 개발용 검증기 |
| 모바일 | 작업 환경: Dart 3.14.1 분석기 + Flutter 3.50.0 소스로 `dart analyze`. CI: Flutter 3.50.0 stable로 `flutter analyze`, Android APK·AAB 빌드(ubuntu), iOS 서명 없는 빌드(macOS) |
| 실기기·시뮬레이터 | **없음** — 앱 화면의 실제 동작은 한 번도 실행해 보지 못했음 |

## 2. 빌드·자동 시험

| 항목 | 기대 | 실제 |
|---|---|---|
| 서버 타입 검사·빌드 | 오류 0 | **통과** |
| 서버 통합 시험 (Redis 없음) | 24건 통과 | **통과** 24/24 (3회 반복) |
| 서버 통합 시험 (Redis 연결) | 24건 통과 | **통과** 24/24 |
| 서버 통합 시험 (GitHub Actions) | 24건 통과 | **통과** |
| 관리자 웹 빌드 (로컬·CI) | 빌드 성공 | **통과** (브라우저로 화면을 직접 열어 보지는 않음) |
| 모바일 정적 분석 (로컬·CI) | 오류 0 | **통과** |
| `tool/bootstrap.py` (android/·ios/ 생성, 권한·아이콘) | 정상 실행 | **통과** (CI에서 실행, iOS 쪽 결과물은 미검증) |
| Android 테스트 APK | APK 생성 | **통과** — Artifacts `eumtalk-test-apk` (디버그 키 서명, 시험용, Firebase 값 미설정이라 푸시 꺼진 상태) |
| Play 제출용 AAB | 업로드 키 서명 | 서명 경로 **통과**(CI 임시 키로 빌드·서명). 실제 업로드 키 서명은 **미검증**(Secrets 없음) |
| iOS 빌드 | Xcode 빌드 | 서명 없는 release 빌드 **통과** (macOS, Firebase·웹뷰 포함, Runner.app 23.5MB) |
| iOS 서명·TestFlight | 업로드 | **미검증** (Apple 계정·인증서 없음) |
| Render 배포 | Blueprint 적용 | **미검증** (배포하지 않음) |

CI 실패 2건은 고친 뒤 다시 통과했습니다: ① Android lint 도구 자체 오류(image_picker_android 의 lintVital) → 해당 검사 끔, ② 서명 설정의 Kotlin DSL 문법 오류 → 수정.

### 통합 시험 24건

1단계(10건): 가입 단계·미성년 차단 / 재로그인 / 운영 환경 설정 누락 시 가입 중단 / 주변 목록과 개인정보 미노출 / 인사→수락→첫 메시지 / 동시 인사 / 끊김 복구 / 차단 / 수신 거부·거절 / 신고 사본

2~5단계(10건):

11. **사진** — 수락 전 업로드 거부, 참여자 열람, 비참여 계정·서명 변조·만료 링크 거부, EXIF(GPS) 제거, 다른 방 사진 첨부 거부, 차단 시 프로필 사진 비공개
12. **그룹방** — 위치 권한 없는 회원의 원주 지역방 참여, 정원 1자리 동시 입장 시 1명만, 차단 회원 메시지 가림, 공지·검색·승인·강퇴·재가입 제한·위임·종료·비밀방
13. **푸시** — 메시지·인사 발송 기록, 미리보기 끄면 내용 제외, 알림 끄기·차단 직후 미발송
14. **대화 부가 기능** — 답장, 대화 내 검색, TXT 내보내기, 나가기 후 새 메시지로 복귀
15. **게시판·장터** — 게시 전 필터(연락처·금칙어), 지역 목록, 댓글·공감·북마크, 거래 문의에 상품명·사진·가격 첨부, 거래 상태
16. **포인트** — 같은 영수증 동시 3회+재처리에도 1회 지급, 타 계정 재사용 거부, 고정 실패(잔액 부족·글 숨김) 시 잔액 유지, 고정 정렬·만료, 원장 기록
17. **구독** — 구매·복원·갱신·환불·만료가 각각 1회만 반영, 프리미엄 혜택
18. **다중 인사·둘러보기** — 수신 거부·차단·대기 중 대상 제외, 실제 발송분만 차감, "이 지역 둘러보는 중" 표시
19. **신고 처리** — 권한 분리, 목록에 내용 미노출, 증거 열람 기록, 숨김 조치의 실시간·재조회 반영, 신고자·대상자 통지, 이력, 정지 중 이의신청, 수락 시 해제, 개인 대화 검색 API 부재
20. **계정 삭제** — 주변·프로필·게시글·방 검색 미노출, 세션·푸시 토큰·사진·개인정보 삭제, 발급된 사진 링크 무효, 보존 대상 유지, 같은 번호 재가입

외부 연동(4건, 모의 서버):

21. **포트원 본인인증** — 인증 페이지에 storeId·channelKey·인증 ID가 들어가고 API 비밀값은 없음, 서버가 `PortOne {secret}` 헤더로 결과 조회, 미완료·내역 없음 처리, 휴대폰 확인·성인 확인 각각 기록, 가입 후 연령대·성별(기본 비공개) 반영, 같은 번호 재인증 시 로그인, 인증 건 재사용 거부, 같은 사람(CI) 다른 번호 가입 거부
22. **본인인증 거절** — 미성년(휴대폰 확인은 기록, 성인 확인은 기록 안 됨), 외국인, 번호·생년월일 누락
23. **사진 판별(Vision)** — API 키·SAFE_SEARCH 요청 형식, 다시 인코딩한 사진 전송, 선정성 높음·폭력 매우 높음 차단, 판별 장애 시 차단, 대화 사진은 판별 안 함, 막힌 사진은 저장 안 됨
24. **FCM 발송** — 서비스 계정 JWT로 토큰 발급, 기기 토큰으로 발송, 알림 제목·내용·열 방(conversationId), 미리보기 끄면 내용 제외, 알림 끄기·차단 후 미발송, 만료 토큰 삭제

## 6. 알고 있는 제한

- 이용규칙·개인정보 안내 문구는 초안
- 본인인증 화면은 앱 웹뷰에서 포트원 브라우저 SDK를 여는 방식이라, PASS 같은 통신사 앱 호출이 있는 채널은 실기기 동작 확인이 필요함
- 시·군·구 목록 중 인천은 2026년 7월 개편안을 기억에 의존해 넣었으므로 대조 필요
- 텍스트 필터는 금칙어·연락처 패턴 방식이라 우회 표현을 모두 막지는 못함(신고·숨김으로 보완)
- Render 무료 플랜에서는 서버 디스크의 사진이 재배포 때 사라짐 → S3 호환 저장소 설정 필요

### 통합 시험 10건

1. 휴대폰 인증과 성인 확인을 각각 거쳐야 가입되고, 미성년(연 나이 19세 미만)은 가입 불가
2. 가입 후 같은 번호로 인증하면 로그인, 로그아웃 후 토큰 무효
3. 운영 환경에 본인확인 설정이 없으면 가입 503 중단 + 관리자 상태에 누락 표시
4. 위치 없이 원주시를 고른 회원끼리 주변에 보임 / 응답에 좌표·거리·전화번호·생년 없음 / 비공개 성별 미전달 / "주변에 나 표시" 끄면 제외
5. 인사 → 수락: 링크 포함 인사 거부, 대기 중 중복 발송 409, 수락 동시 2회에도 방 1개, 두 접속 모두 같은 방 알림 1회, 첫 메시지 실시간 수신, 읽음 전달, 비참여 계정 접근 404
6. 서로 동시에 인사 → 방 1개
7. 접속이 끊긴 동안 온 메시지를 재접속 후 빠짐없이 수신, 같은 메시지 3회 재전송에도 1건
8. 차단 직후 메시지 403, 인사 403, 실시간 알림 없음, 양쪽 주변·프로필에서 제외
9. "새 인사 받기" 끈 회원에게 발송 불가, 거절 후 재발송 불가
10. 신고 시 서버가 문제 메시지 본문·시점을 사본으로 기록, 비참여 대화 메시지는 신고 대상 조회 불가

## 5. 1단계에서 알고 있는 제한

- 프로필 사진: 자리만 있고 업로드는 2단계(비공개 저장소 연동)에서 추가
- 푸시 알림: 2단계. 지금은 앱이 켜져 있을 때 실시간 수신, 다시 켜면 동기화
- 채팅 부가 기능(답장 UI, 대화 내 검색, 알림 끄기, 방 나가기, TXT 내보내기): 서버에 답장 필드만 있고 화면은 2단계
- 다중 쪽지, 다른 시·도 둘러보기: 5단계(포인트). 지금은 내 시·도 안에서만 지역 선택 가능
- 계정 삭제 신청, 이의신청: 4단계
- 이용규칙·개인정보 안내 문구는 초안
